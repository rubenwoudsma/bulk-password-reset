Bulk Password Reset — directory banner

The current banner shows the recommended reset-link flow: choose users, review
the reset, then send links. It replaces the inherited screenshot montage of the
1.x interface. The palette follows the existing teal/mint plugin icon. There is
no release number in the artwork, so a routine patch release does not date it.

WordPress.org assets:
- .wordpress-org/banner-772x250.png: standard banner, 772 by 250 pixels.
- .wordpress-org/banner-1544x500.png: Retina banner, 1544 by 500 pixels.

Both are RGB PNGs below WordPress.org's 4 MB banner limit. Keep both sizes;
WordPress.org does not use a Retina banner on its own. The old JPG is removed
to avoid competing files for the standard banner size. Directory artwork is
outside the runtime ZIP and is uploaded only through an authorized SVN release.

Version choice:
The listing copy and banner accompany the still-unpublished 2.0.1 maintenance
candidate. No 2.0.2 bump is needed, and the published 2.0.0 source/tag is unchanged.
SVN assets are not intrinsically tied to the plugin version; keeping them with
2.0.1 is a release choice, not a WordPress.org requirement. Merging the PR does
not publish a GitHub Release or upload to SVN.

Creation and export:
Created on 25 November 2026 with the built-in image generator, using the existing
.wordpress-org/icon-256x256.png as the visual reference. The selected image was
mechanically centre-cropped to the required 1544:500 aspect ratio and exported at
the two exact sizes with high-quality bicubic resampling. Text and illustrations
were visually checked at the standard display size. No plaintext passwords or
claims of guaranteed email delivery are shown. The existing plugin license
applies to these repository assets.
